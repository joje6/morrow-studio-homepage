# 모로우 스튜디오

한국어로 구성된 반응형 크리에이티브 스튜디오 랜딩 페이지 샘플입니다. HTML, CSS, JavaScript만으로 구성되어 별도 설치나 빌드 과정 없이 정적 웹 서버에서 바로 제공할 수 있습니다.

## 실행

저장소 루트의 `index.html`을 브라우저에서 열거나 원하는 정적 호스팅 서비스에 저장소를 연결하세요. 앱 카탈로그 `web`의 정적 사이트 소스로 사용할 수 있습니다.

## 구성

- `index.html` — 한국어 콘텐츠 및 페이지 구조
- `styles.css` — 반응형 레이아웃, 색상, 프로젝트 미리보기 그래픽
- `script.js` — 모바일 내비게이션 토글

프로젝트 사례와 연락처는 데모용 허구 콘텐츠입니다. Google Fonts 연결이 차단되면 시스템 기본 글꼴로 표시됩니다.
